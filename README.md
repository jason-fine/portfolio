# Jason Fine's Portfolio

A modern, responsive, and SEO-optimized portfolio website built with Next.js 16, TypeScript, and Tailwind CSS. This portfolio showcases my skills, experience, and projects with an elegant interface designed for optimal performance and user experience.

## 🚀 Live Demo

View the live portfolio at [https://jasonfine.dev/](https://jasonfine.dev/)

## ✨ Key Features

- **Professional Experience Timeline**: Showcases my career journey with a visually appealing timeline
- **Project Showcase**: Displays my technical projects with detailed information and live demos
- **Multiple Themes**: Dark, Light, Retro, Cyberpunk, Aurora, Synthwave, and Paper themes
- **Responsive Design**: Optimized for all devices (mobile, tablet, desktop)
- **100% Performance Score**: Fully optimized for speed and Core Web Vitals
- **SEO-Ready**: Structured data, meta tags, and optimized content
- **Modern Tech Stack**: Next.js 16, React 19, TypeScript, Tailwind CSS, and shadcn/ui
- **Easy Customization**: Well-organized code structure with minimal effort required
- **Animations**: Subtle animations for engaging user experience
- **Analytics Integration**: Ready for Google Analytics tracking
- **Contact Form**: Functional contact form with validation

## 🛠️ Tech Stack

- **Framework**: Next.js 16 with Turbopack
- **Language**: TypeScript
- **UI Library**: React 19
- **Styling**: Tailwind CSS + shadcn/ui
- **Animations**: Framer Motion
- **Form Handling**: Server actions with validation
- **Analytics**: Google Analytics + Vercel Analytics
- **Deployment**: Vercel

## 📱 Performance and Responsiveness

This portfolio is optimized for:

- **Speed**: Fast page loads and transitions
- **Accessibility**: WCAG compliant for all users
- **SEO**: Structured data and meta tags
- **Mobile-First**: Responsive on all devices
- **Core Web Vitals**: Excellent scores across all metrics

## 🔧 Local Development

```bash
# Clone the repository
git clone [https://github.com/jasonfine/portfolio.git](https://github.com/jasonfine/portfolio.git)

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
